# Glass Glow — النسخة النهائية المعدلة

## ما تم تحديثه

- توحيد اسم العلامة الظاهر في المتجر ولوحة الإدارة إلى **Glass Glow**.
- حذف السطر الموجود أسفل اسم المتجر من الترويسة.
- إزالة شريط الإعلان العلوي لتقليل التشتت والتركيز على المنتجات.
- إزالة نص الصور الإضافية من صفحة المنتج مع الإبقاء على الصور المصغرة نفسها.
- إزالة قسم مميزات البوكسات من صفحة المنتج.
- تغيير عنوان المنتجات المشابهة إلى: **منتجات أخرى من نفس الفئة**.
- جعل بطاقات المزايا والتوصيل تظهر في الصفحة الرئيسية فقط دون صفحات المنتج أو الإدارة.
- حذف الحقوق والنصوص السفلية الخاصة بالدفع والتوصيل من التذييل.
- إضافة تصنيفات مخصصة من لوحة الإدارة، وتظهر تلقائيًا كفلاتر في المتجر.
- تغيير نموذج المنتج ليقبل الصور نفسها من الجهاز عبر اختيار الملفات، مع دعم حتى 6 صور لكل منتج، بدل طلب روابط الصور.
- إضافة تخزين الصور كبيانات صورة داخل المنتج حتى تبقى الصورة مرتبطة بالمنتج دون رابط خارجي.
- إضافة ترحيل تلقائي لقاعدة البيانات القديمة لإنشاء جدول التصنيفات دون توقف الخادم.
- معالجة أخطاء الخادم مع تسجيلها وإرجاع رد JSON واضح بدل توقف الخدمة.
- إضافة أيقونة بسيطة للمتجر بجانب عنوان الصفحة.
- التأكد من عدم وجود النصوص التي طلب حذفها داخل الواجهة.

## التشغيل

```bash
npm install --legacy-peer-deps
npm run lint
npm run build
NODE_ENV=production npm start
```

لوحة الإدارة:

- `/admin/orders`
- `/admin/products`
- `/admin/wilayas`
- `/admin/settings`

كلمة مرور الإدارة الحالية: `demo360`.

> ملاحظة: يستخدم التطبيق JSON داخليًا لطلبات API وتخزين مصفوفة الصور في قاعدة البيانات، لكن لا توجد ملفات JSON للمنتجات أو الإعدادات ضمن واجهة المتجر.
